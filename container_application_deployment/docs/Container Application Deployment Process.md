# PIFSC Staff Information Application - Container Application Deployment Process Documentation

## Overview
The PIFSC Container Application Deployment (CAD) project was created to provide a set of reusable scripts that can be used to deploy a container application in a variety of scenarios. The intent is to minimize the amount of custom code necessary to deploy a given container application by leveraging the CAD. This module is intended to be implemented as a git submodule to make it easy to include in a given application's repository and updated periodically to take advantage of upgrades to the CAD. The PIFSC Staff Information Application (SIA) data system implements the CAD for several scenarios.
